# TITAN GUARD CORPORATE — Black Gold 3D
Unggah empat file website ke root repositori GitHub Pages: `index.html`, `styles.css`, `app.js`, `README.md`. Pastikan nama halaman `index.html` huruf kecil. Di Settings > Pages pilih Deploy from a branch, branch `main`, folder `/ (root)`.

## Fitur
Profil, layanan, biaya simulasi, formulir lamaran, tes logika 10 soal dengan nilai otomatis 0–100, kontak email, desain responsif HP.

## PENTING
- Form lamaran hanya demo front-end. Data tidak disimpan dan tidak terkirim ke HRD. Perlu backend/layanan formulir aman untuk menerima lamaran sungguhan.
- Kontak adalah placeholder; ganti email, nomor, alamat.
- Tarif Rp6,5 juta dan Rp8,5 juta adalah simulasi contoh, bukan tarif resmi/pasar. Hitung ulang berdasarkan upah, BPJS, THR, jam kerja, perlengkapan, pajak, risiko, lokasi, dan margin.
- Tes ini bukan tes IQ klinis/terstandar dan tidak dapat membuktikan IQ 120. Untuk pengukuran IQ resmi gunakan alat psikometri tervalidasi dengan psikolog/asesor kompeten.
- Sebelum menawarkan jasa keamanan, pastikan badan usaha memenuhi perizinan BUJP/SIO dan ketentuan Polri serta ketenagakerjaan. Persyaratan khusus mencakup antara lain kualifikasi Satpam minimal Gada Pratama dan BPJS untuk usaha penyediaan tenaga pengamanan. Verifikasi persyaratan terbaru kepada Ditbinmas Polda dan OSS.
- Hero dan font mengambil aset eksternal Unsplash/Google Fonts.
