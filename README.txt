TITAN GUARD CORPORATE — Prototype Website
==========================================

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka index.html menggunakan browser modern (Chrome, Edge, Firefox).
3. Tidak membutuhkan instalasi atau server untuk demo lokal.

FITUR
- Landing page tema black-gold dengan efek visual 3D.
- Formulir lamaran untuk Front Service, Inteligent Service, Cyber Service, Eyes Service.
- Ujian 20 soal hanya terbuka setelah pendaftaran berhasil.
- Timer 20 menit, penilaian otomatis (5 poin/soal), lulus minimal 80.
- Dashboard HRD dengan ringkasan pelamar, hasil ujian, data client, dan ekspor CSV.
- Formulir permintaan jasa keamanan client dengan harga awal Rp8.000.000.

PENTING — BATASAN PROTOTIPE
Ini adalah prototipe front-end. Data disimpan pada localStorage browser/perangkat yang digunakan.
PIN dashboard berada di sisi browser dan BUKAN sistem autentikasi aman. Data tidak otomatis terkirim
ke HRD atau server pusat, tidak tersinkron antar perangkat, dan dapat hilang jika data browser dihapus.
Jangan gunakan untuk mengumpulkan data pribadi nyata sebelum memasang backend/database, HTTPS,
autentikasi server-side, kontrol akses, backup, kebijakan privasi, dan persetujuan pemrosesan data.
Sebelum operasional, tinjau kembali legalitas dan ruang lingkup layanan keamanan serta ketentuan harga.
